One package, nineteen platforms

bigdata-php connects to SQL and OLAP engines, the Hadoop ecosystem, schedulers, lakehouse metadata catalogs, and NoSQL stores through one PHP API.

HTTP drivers work out of the box; optional dependencies for Doris, StarRocks, Hive, and Cassandra are checked only when that driver is created.

  • One entry point, isolated drivers
  • Optional dependencies on demand
  • Six frameworks share one Manager

A round yellow cartoon hamster wearing a cyan data scarf and a database tag made of 19 platforms.

Nineteen platforms, one API.

One entry point, many drivers

Drivers are created on demand and cached by name, with no unified SQL layer.

Unified driver management

BigData::driver creates and caches instances by name; unknown keys are rejected.

Optional dependencies

pdo_mysql, thrift, and php-cassandra are checked only when their driver is created.

SQL and OLAP

Trino, Doris, StarRocks, Kylin, and Druid share one result convention.

Hadoop and lakehouse

WebHDFS, YARN, Hive, Spark, Flink, plus read-only lakehouse metadata.

Scheduling and NoSQL

Airflow, DolphinScheduler, Oozie, HBase, and Cassandra.

Six framework adapters

Laravel, ThinkPHP, Webman, Hyperf, Yii2, and Yii3.

Install and use

Install first, then run a minimal example.

PHP 8.0+ / Guzzle 7Full README
Install
composer require erikwang2013/bigdata-php
Minimal example
use Erikwang2013\BigData\BigData;

$trino = BigData::driver('trino', [
    'host' => '127.0.0.1',
    'port' => 8080,
    'user' => 'php',
    'catalog' => 'hive',
    'schema' => 'default',
]);

$result = $trino->query('SELECT 1 AS id');

foreach ($result->rows() as $row) {
    echo $row[0], PHP_EOL;
}
Laravel 9 / 10 / 11Full README
Install
composer require erikwang2013/bigdata-php
php artisan vendor:publish --tag=bigdata-config
Minimal example
// bootstrap/providers.php (Laravel 11)
return [
    Erikwang2013\BigData\Integration\Laravel\BigDataServiceProvider::class,
];

$trino = app(\Erikwang2013\BigData\Integration\Manager::class)->driver('trino');
